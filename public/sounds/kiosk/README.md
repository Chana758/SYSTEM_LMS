# សម្លេង Kiosk (ស្រេចចិត្ត)

ដាក់ឯកសារ MP3 ខ្លីៗ (1–3 វិនាទី) ដែលថតជាសំឡេងខ្មែរ នៅក្នុង Folder នេះ។
បើមានឯកសារ Kiosk លេងវា។ បើគ្មាន វាប្រើ Text-to-Speech របស់ Tablet (បើមានសំឡេងខ្មែរ)។

| ឯកសារ | និយាយថា |
| --- | --- |
| `welcome.mp3` | សូមស្វាគមន៍ |
| `goodbye.mp3` | លាហើយ សូមអរគុណ |
| `already_in.mp3` | អ្នកបានចូលរួចហើយ |
| `not_in.mp3` | ទ្វារបើកឲ្យចេញ |
| `denied.mp3` | សូមទាក់ទងបណ្ណារក្ស |
| `guest.mp3` | សូមស្វាគមន៍ភ្ញៀវ |
| `reminder.mp3` | អ្នកមានសៀវភៅត្រូវសងឆាប់ៗនេះ |

ថតដោយទូរស័ព្ទ រួចកាត់ឲ្យខ្លី ហើយ Export ជា MP3។
